Sobre nosotros

Quienes somos

BOL Store es una tienda de ropa urbana que nacio en Santiago de Chile. Partimos vendiendo poleras estampadas entre amigos y hoy tenemos cinco lineas de productos: poleras, polerones, jockeys, zapatillas y cargos.

Trabajamos con talleres chicos de Santiago Centro. Cada diseño se produce en tiradas de maximo cien unidades, asi que el stock que aparece en cada producto es el que realmente tenemos.

Que nos importa

  • Produccion local, sin intermediarios
  • Tiradas cortas para no acumular ropa sin vender
  • Precios directos, sin descuentos inflados
  • Cambios dentro de 30 dias sin preguntas

El equipo de desarrollo

Este sitio web fue desarrollado como proyecto de la asignatura DSY1104 Desarrollo Fullstack II, de la Escuela de Informatica y Telecomunicaciones de Duoc UC.

Tomas Salas

Desarrollo frontend

A cargo de la estructura HTML, la hoja de estilos, el catalogo de productos y el carrito de compras.

Como esta hecho el sitio

  • HTML5 con etiquetas semanticas
  • Hoja de estilos CSS propia y externa
  • Bootstrap 5 solo para el sistema de grilla
  • JavaScript para el catalogo, el carrito y las validaciones
  • localStorage para guardar el carrito en el navegador
  • Git y GitHub para el control de versiones
