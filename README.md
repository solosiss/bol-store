# BOL Store - Tienda de ropa

Proyecto de la asignatura DSY1104 Desarrollo Fullstack II, Duoc UC.
Evaluacion Parcial 1. Tienda online hecha con HTML, CSS y JavaScript.

## Tecnologias

- HTML5
- CSS (hoja de estilos propia y externa)
- Bootstrap 5, usado solo para la grilla de columnas
- JavaScript
- localStorage para guardar el carrito

## Archivos

```
index.html         Pagina principal
css/styles.css     Hoja de estilos
js/productos.js    Arreglo con los productos
js/main.js         Carrito y listado de productos
img/               Imagenes del sitio
docs/              Documento ERS y planilla de requerimientos
```

## Como abrirlo

Abrir index.html con el navegador, o usar la extension Live Server de VS Code.
